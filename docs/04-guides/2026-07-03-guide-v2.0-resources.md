## 一、云端 ASR 服务

### MiMo ASR（小米）
- 文档：https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/audio/Speech-Recognition
- API 端点：`POST https://api.xiaomimimo.com/v1/chat/completions`
- 协议：OpenAI 兼容（chat completions）
- 音频格式：WAV/MP3，Base64 编码，上限 10MB
- 流式：支持（`stream: true`）
- 语言：auto / zh / en
- 定价：¥0.5/小时
- 模型：mimo-v2.5-asr
- 注意：V2 系列已于 2026.6.30 下线，需用 V2.5 系列

### 讯飞（iFLYTEK）
- 实时转写文档：https://www.xfyun.cn/doc/asr/rtasr/API.html
- 声纹注册文档：https://www.xfyun.cn/doc/spark/asr_llm/voice_print.html
- WebSocket 端点：`wss://rtasr.xfyun.cn/v1/ws`
- 说话人分离：`roleType=2`，返回 `rl` 字段（仅切换时非零）
- 声纹注册：HTTP REST，返回 `feature_id`
  - 注册：POST `https://office-api-personal-dx.iflyaisol.com/res/feature/v1/register`
  - 更新：POST `https://office-api-personal-dx.iflyaisol.com/res/feature/v1/update`
  - 删除：POST `https://office-api-personal-dx.iflyaisol.com/res/feature/v1/delete`
- 鉴权：HMAC-SHA1（appid + ts + apiKey）
- 音频要求：16K/16bit/单声道/pcm_s16le
- 特色：12 个垂直领域参数（court/edu/finance 等）

### 腾讯云
- 实时说话人分离：https://cloud.tencent.com/document/product/1093/57970
- 录音文件识别：https://cloud.tencent.com/document/product/1093/36394
- 说话人分离：`SpeakerId` 字段（每条结果都携带）
- 声纹识别：独立产品线，支持 1:1 比对和 1:N 检索
- 定价：角色分离预付费 0.3 元/小时起
- 免费额度：实时语音 5 小时/月

### 阿里云
- 智能语音交互（NLS）：https://www.aliyun.com/product/nls
- 文档可能已迁移，URL 返回 404
- 支持说话人分离、声纹注册

### 百度
- 语音识别：https://ai.baidu.com/tech/speech
- 无独立说话人分离 API
- 宣称 98% 中文准确率
- 不推荐用于会议转写场景

## 二、本地推理框架

### FunASR GGUF 运行时
- GitHub：https://github.com/modelscope/FunASR/tree/main/runtime/llama.cpp
- Releases：https://github.com/modelscope/FunASR/releases/tag/runtime-llamacpp-v0.1.4
- 支持模型：SenseVoice / Paraformer / Fun-ASR-Nano
- 不含 CAM++（说话人分离）
- SenseVoice GGUF q8：254MB，CER 8.01%
- FSMN-VAD GGUF：1.7MB

### ONNX Runtime
- GitHub：https://github.com/microsoft/onnxruntime （21k Stars，MIT）
- Rust 绑定：`ort` crate（https://crates.io/crates/ort）
- 当前版本：v1.27.0
- 支持平台：Windows/macOS/Linux/Android/iOS
- 支持硬件加速：CPU/GPU（CUDA/TensorRT/CoreML）

### Whisper.cpp
- GitHub：https://github.com/ggerganov/whisper.cpp （51.3k Stars）
- 纯 C/C++，无 Python 依赖
- 中文效果差（CER 20-31%），不推荐

## 六、技术参考

### fbank 特征提取步骤
1. 预加重滤波：`y[i] = x[i] - 0.97 * x[i-1]`
2. 分帧：25ms 窗口，10ms 步长
3. 加窗：汉明窗
4. FFT：512 点
5. Mel 滤波器组：80 个滤波器
6. 对数能量：`log(filter_energy + 1e-10)`
7. 输出：80 维 fbank 特征向量

### 说话人聚类算法
- 层次聚类（Agglomerative Clustering）
- 距离度量：1 - cosine_similarity
- 链接方式：average linkage
- 停止条件：距离阈值或预设说话人数量

### CAM++ 嵌入向量比对
- 维度：192
- 相似度：余弦相似度 `dot(a,b) / (norm(a) * norm(b))`
- 阈值：0.31（官方推荐），0.55（HIGH_CONFIDENCE）
- 同一人多次录音取平均嵌入
