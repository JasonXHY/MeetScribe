## 一、验证目标

评估 v2.0 C 版能否将 CAM++ 声纹模型脱离 Python/PyTorch 在本地运行，实现企业共享 API key 场景下的本地声纹匹配。

## 二、验证项与结论

### 验证项 1：CAM++ ONNX 导出

**方法**：查阅 FunASR 官方文档和源码

**结论**：✅ 可行

**依据**：
- FunASR 官方教程提供 ONNX 导出功能：`model.export(quantize=False)`
- CAM++ 在 FunASR Model Zoo 中有明确条目（7.2M 参数）
- 模型代码位于 `funasr/models/campplus/`
- ONNX 导出机制对所有 FunASR 注册模型通用

**导出命令**：
```python
from funasr import AutoModel
model = AutoModel(model="cam++", device="cpu")
model.export(quantize=False)  # 导出到模型缓存目录
```

**预期模型大小**：~30MB（FP32），量化后更小

**注意事项**：
- 需要 Python 环境进行一次性导出（开发/构建阶段）
- 导出后运行时不需要 Python
- 需验证导出后的 ONNX 模型推理结果与 PyTorch 一致性

### 验证项 2：Rust fbank 特征提取

**方法**：调研 Rust 音频处理生态

**结论**：✅ 可行（需自实现，约 80-100 行代码）

**Rust 生态关键库**：

| 库 | 版本 | 用途 |
|---|---|---|
| rustfft | 6.4.1 | 高性能 FFT（支持 AVX/SSE4.1/NEON SIMD） |
| ndarray | 0.17.2 | N 维数组运算（类似 NumPy） |
| ort | 2.0.0-rc.12 | ONNX Runtime Rust 绑定 |

**fbank 实现步骤与代码量**：

| 步骤 | 实现方式 | 预估行数 |
|------|---------|---------|
| 预加重滤波 | IIR 滤波 `y[i] = x[i] - α*x[i-1]` | ~10 行 |
| 分帧加窗 | 汉明窗 + 滑动窗口 | ~15 行 |
| FFT 变换 | `rustfft` crate | ~5 行 |
| Mel 滤波器组 | 预计算三角滤波器矩阵，矩阵乘法 | ~30 行 |
| 对数能量 + DCT | `ndarray` 的 log 和手动 DCT | ~20 行 |

**关键依赖**：
```toml
[dependencies]
rustfft = "6.4"
ndarray = "0.17"
ort = "2.0"
```

**是否有现成库**：Rust 生态中没有现成的 fbank crate，需自行实现。但复杂度低，参考实现路径清晰。

### 验证项 3：FunASR GGUF 运行时

**方法**：查阅 FunASR GitHub 和 HuggingFace

**结论**：✅ 可用（但不含 CAM++）

**已支持的模型**：
- SenseVoiceSmall：ASR + 情感 + 事件（q8 量化 254MB）
- Paraformer：中文 ASR
- Fun-ASR-Nano：多语言 LLM-ASR
- FSMN-VAD：语音端点检测（1.7MB）

**未支持**：CAM++（说话人分离）未被移植到 GGUF 运行时

**意义**：ASR 部分可用 GGUF 方案做本地 fallback，但声纹匹配仍需 ONNX 方案

---

### 验证项 4：MiMo ASR API

**方法**：查阅 MiMo 官方文档

**结论**：✅ 可用（但无说话人分离）

**API 规格**：
- 端点：`POST https://api.xiaomimimo.com/v1/chat/completions`
- 协议：OpenAI 兼容
- 音频输入：Base64 WAV/MP3，上限 10MB
- 流式支持：有
- 定价：¥0.5/小时
- 认证：api-key header

**限制**：只返回转写文本，不返回说话人分离结果、不返回时间戳

## 三、C 版技术架构验证结论

| 能力 | 方案 | 可行性 | 安装包增量 |
|------|------|--------|-----------|
| ASR 转写 | 云端 API（MiMo/讯飞/腾讯云） | ✅ | 0 |
| 说话人分离 | 云端 API（讯飞/腾讯云） | ✅ | 0 |
| 声纹匹配 | CAM++ ONNX 本地推理 | ✅ | ~30MB |
| fbank 前端 | Rust 自实现（rustfft + ndarray） | ✅ | 0（编译进二进制） |
| 说话人聚类 | Rust 实现层次聚类 | ✅ | 0 |
| AI 摘要 | 云端 LLM API | ✅ | 0 |
| UI 框架 | Tauri（Rust + Web） | ✅ | ~2MB |
| **总计** | | | **~32MB** |

**核心结论**：C 版安装包可控制在 32MB 左右（对比 v1.0 的 ~2GB，减少 98%），同时保留本地声纹匹配能力。
